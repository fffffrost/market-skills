# 审稿前，把未确认的事项写清楚

> 合成教学示例；AI生成、经自动校验、未经人工审核。青禾协作台为虚构产品。此稿是Codex在小麦隔离运行第二版基础上的校订稿，不是未经改动的模型输出。

审稿时，如果还不知道一条数据由谁核对、一个说法是否确认，可以先把这些问题列进清单。这是本文设定的编辑场景，不是用户访谈或行业统计。

青禾协作台面向已有客户的运营负责人，提供内容审核清单功能。你可以在一条内容下添加审核事项、责任角色和待确认备注。

使用时，先打开内容记录，再填写审核清单、指定责任角色，最后记录未确认事项。把要核对的内容和负责核对的角色写在一起，作为后续审核的记录。

这项功能不自动核验外部数据，也不自动向公众号发文；文章对外发布仍由团队自行操作。它不能替代事实核对或发布操作，也没有已验证的节时比例、排名、客户评价或上线日期可供本文引用。
