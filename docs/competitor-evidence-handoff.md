# Competitor evidence handoff / 竞品证据交接

A worked exercise for [research-competitors](../skills/research-competitors/SKILL.md). Use it with the [research template](../skills/research-competitors/references/research-template.md). The inputs below are fictional teaching cards, not vendor research, customer results, or a record of an agent run. No hosted Mika account is needed to read or reuse this exercise.

这是现有竞品研究 Skill 的操作示例：把材料中的说法改成范围明确、可以继续核验的交接记录。以下产品、套餐与来源均为虚构教学卡片；不是厂商调查、客户成果或 Agent 执行记录。阅读和使用本示例不需要 Mika 账号。

## 1. Define the decision / 先限定决定

**Decision:** Which options should enter the next product demonstration? The exercise does not select a purchase winner. Pricing, feature availability and suitability remain unknown unless the supplied evidence supports them.

**决定：** 哪些方案值得进入下一轮产品演示？此处不作采购排名；没有证据支持的价格、功能与适用性保持未知。

## 2. Supplied cards / 输入卡片

| ID | English | 中文 |
| --- | --- | --- |
| S1 | Fictional Alpha: per-seat billing; displayed monthly equivalent requires annual payment. No amount or plan name provided. | 虚构甲：按席位计费，展示年付折算月价；没有金额或套餐名。 |
| S2 | Fictional Beta: per-project billing, paid monthly. No amount or plan name provided. | 虚构乙：按项目计费，按月支付；没有金额或套餐名。 |
| S3 | Alpha's fictional feature card mentions draft export. It says nothing about approval roles, revision history or automatic publishing. | 甲的虚构功能卡只提到导出草稿，没有说明审核角色、修订记录或自动发布。 |

Card version: 2026-09-14. This is the exercise creation date, not a vendor access date. No product was tested. Region, currency, taxes, usage volume and extra services are unspecified.

卡片版本：2026-09-14。这是示例编写日期，不是厂商资料访问日期。本示例未测试任何产品，地区、币种、税费、使用量和附加服务均未提供。

## 3. Three transformations / 三个改写例子

| Tempting claim / 容易写出的结论 | Evidence-bound handoff / 可交接表述 | Next action / 下一步 |
| --- | --- | --- |
| “Beta is cheaper.” / “乙更便宜。” | S1 and S2 use different billing units and payment periods. Total cost is unknown. / S1与S2的计费单位、付款周期不同，总成本未知。 | Define seats/projects and a common period, then obtain comparable quotes. / 明确席位、项目数和统一周期，再取得可比报价。 |
| “Alpha cannot approve drafts.” / “甲不能审核草稿。” | S3 does not establish whether approval roles exist. Absence from this card is not evidence of absence. / S3没有说明是否有审核角色；卡片未提及不等于产品不支持。 | Request current documentation or demonstrate edit/review permissions. / 查当前文档或演示编辑、审核权限。 |
| “Alpha publishes content automatically.” / “甲可以自动发布内容。” | S3 describes draft export only; publishing is outside the supported claim. / S3只描述导出草稿，不能推断自动发布。 | Verify publishing separately only if it affects the decision. / 若影响当前决定，单独核验发布能力。 |

These examples demonstrate how to record uncertainty. They do not establish the actual capabilities of any product.

这些例子演示未知信息的记录方式，不证明任何真实产品的能力。

## 4. Copyable evidence ledger / 可复制证据表

| Evidence ID / 编号 | Question / 问题 | Product and plan / 产品套餐 | Source / 来源 | Supported statement / 支持的说法 | Status / 状态 | Missing evidence / 缺口 | Owner / 责任角色 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| E1 | Can total cost be compared? / 总成本可直接比吗？ | Alpha/Beta; plans unknown / 甲乙，套餐未知 | S1, S2 | Billing units and periods differ / 单位、周期不同 | Unknown total cost / 总成本未知 | Comparable quotes and usage assumptions / 可比报价与使用假设 | Research owner / 研究负责人 |
| E2 | Are approval roles supported? / 支持审核角色吗？ | Alpha; plan unknown / 甲，套餐未知 | S3 | Card covers export, not role permissions / 卡片只描述导出 | Unknown / 未知 | Documentation or demonstration / 文档或演示 | Product reviewer / 产品审核人 |
| E3 | Is automatic publishing supported? / 支持自动发布吗？ | Alpha; plan unknown / 甲，套餐未知 | S3 | Export does not establish publishing / 导出不能证明发布 | Unknown / 未知 | Publishing workflow evidence / 发布流程证据 | Product reviewer / 产品审核人 |

For a real task, replace card IDs with the exact source location, record the actual access date, market, currency and plan, and preserve contradictory sources. Apply the evidence categories from the Skill: hands-on verified, official public information, official self-description, analysis inference, or unknown. Fictional cards must not be labeled official information or hands-on verification.

真实任务要将卡片编号替换为准确来源位置，并记录实际访问日期、市场、币种和套餐；冲突来源并列保留。沿用 Skill 的证据分类：实测验证、官方公开信息、官方自述、分析推断或未知。不能把虚构卡片标成官方信息或实测结果。

## 5. Brief to run yourself / 可复制的执行任务

```text
Use research-competitors with the three fictional cards in this exercise.
The decision is which options to demonstrate next, not which to purchase.
Return a short decision summary, an evidence ledger, and a verification
checklist with role owners. Cite S1/S2/S3. Do not browse for these fictional
products. Keep total cost, approval roles and publishing unknown where
unsupported. Do not invent prices, vendor URLs, test results or a winner.
```

```text
使用 research-competitors，依据本示例的三张虚构卡片工作。
决定范围是筛选下一轮演示对象，不是确定采购赢家。
交付简短决定摘要、证据表、附责任角色的核验清单，引用S1/S2/S3。
不要联网查找虚构产品；缺少支持时，总成本、审核角色和发布能力保持未知。
不编造价格、厂商链接、实测结果或排名。
```

## 6. Acceptance check / 验收

- Each conclusion identifies the card that supports it; unsupported conclusions remain unknown. / 每条结论对应来源，缺乏支持的结论保持未知。
- Different units and payment periods are not treated as comparable prices. / 不把不同单位和付款周期当作可比价格。
- Missing information is not converted into a negative feature claim. / 不将未提及改成不支持。
- Each important unknown has a verification action and role owner. / 重要未知项有核验动作与责任角色。
- The result does not claim real vendor research, completed tests, or human approval. / 不冒充真实厂商调查、已完成测试或人工审核。
