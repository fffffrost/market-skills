# MARKET//SKILLS public repository rules

- Before project work, read the local `PROJECT.md` and the latest entries in `WORKLOG.md`, then verify the actual repository state.
- Keep this repository limited to installable Skill sources, their metadata, validation, documentation, and public feedback configuration. Do not add website application code, production operations, credentials, or unpublished work materials.
- Every Skill must follow the Open Agent Skills directory structure and pass `npm run verify`.
- Make the smallest change that directly serves the requested outcome; do not refactor unrelated files.
- Keep `PROJECT.md` as the latest local status snapshot and append work records immediately above the final `<!-- WORKLOG_APPEND_POINT_DO_NOT_REMOVE -->` marker in `WORKLOG.md`.
- Never commit accounts, keys, tokens, client material, internal metrics, or other sensitive information.
