## Mermaid 骨架

```mermaid
flowchart TD
    A[收到任务] --> B[检查输入]
    B --> C{满足条件?}
    C -->|是| D[执行并记录]
    C -->|否| E[补充或退回]
    D --> F[交接下一负责人]
    E --> B
```

## 交付检查

- 每条路径是否都有终点或回路条件？
- 是否标出负责人变化和记录要求？
- 图内规则与图外规则表是否一致？
- 一线人员能否只看图知道下一步？
