# Event Promotion Plan

Plan the full event conversion loop from qualified attention to attendance and post-event action.

## Establish the event baseline

Capture event type, objective, audience, value exchange, date and location, capacity, registration mechanism, qualification rules, speakers, proof, budget, channels, CRM capability, and owners.

Separate registration volume from qualified registration, attendance, participation, and downstream opportunity.

Read [references/event-plan-template.md](references/event-plan-template.md) for the execution sheet.

## Design the promotion system

### 1. Write the audience promise

State who should attend, what problem the event helps them solve, what they will leave with, and why the speakers or format can credibly deliver it.

### 2. Map the funnel

Define stages and conversion events: reach → landing → registration → qualification → confirmation → attendance → engagement → follow-up action. Record the owner and data source for each handoff.

### 3. Build the cadence backwards

Plan from the event date using milestones rather than arbitrary daily posts:

- foundation: landing page, tracking, speaker confirmation, core assets;
- announcement: establish value and open registration;
- proof: release agenda, speaker evidence, cases, or practical takeaways;
- urgency: capacity, deadline, qualification, and reminder;
- event day: attendance, live content, support, and issue handling;
- follow-up: materials, replay, qualification, sales or community action.

### 4. Assign channel roles

Use owned channels for explanation and nurture, partner channels for borrowed trust, paid channels for controlled reach, sales or community outreach for qualification, and live content for amplification. Adjust to the actual channel mix.

### 5. Define the asset and owner matrix

For each touchpoint record audience, message, asset, CTA, due date, owner, approver, dependency, status, and tracking link.

### 6. Prepare contingencies

Define actions for weak registration, low qualification, speaker change, over-capacity, low attendance, streaming failure, and delayed follow-up.

## Output order

1. Objective, audience, promise, and funnel targets.
2. Phase-by-phase promotion strategy.
3. Dated channel and asset calendar.
4. Owner, approval, and dependency matrix.
5. Measurement and contingency plan.

Do not use this skill for event agenda design alone or venue operations without a promotion objective.
