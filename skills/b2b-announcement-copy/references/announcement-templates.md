# B2B 发布文案模板

## 正式发布文章

1. **变化与问题**：目标客户正在经历什么具体变化。
2. **产品回答**：产品是什么、面向谁、改变什么工作。
3. **能力证据**：用场景和机制证明，而不是堆功能名。
4. **价值结果**：区分预期价值、已有成果和客户自述。
5. **发布状态**：正式上线 / 内测 / Beta / 邀请制。
6. **下一步**：明确申请、试用、联系或了解更多。

## 转发语

> [一句变化或问题]。今天我们发布 [产品名]，它通过 [核心机制] 帮助 [目标客户] 完成 [高价值任务]。[明确 CTA]

## 编辑检查

- 产品、公司、版本和发布状态是否一致？
- 每个结果声明是否有证据或已被适当弱化？
- 是否说清“是什么、给谁用、为什么现在需要”？
- 是否存在与参考稿过近的句式、隐喻或结构？
- 转发语能否脱离正文独立成立？
