## 常用结构

### 公众号转发语

变化或问题 → 核心发现 → 为什么值得读 → 链接行动。

### 社媒短帖

一个鲜明判断 → 两到三个证据点 → 可应用的结论 → 轻量互动。

### 短视频口播

3 秒口语钩子 → 现象 → 核心解释 → 一个例子 → 行动或问题。

### 销售赋能卡片

客户情境 → 关键痛点 → 对应能力 → 可证明结果 → 下一步问题。
